
# Project Brief

## Overview

Building an informative web site about the mining equipment installed.

## Core Features

-   Summarizes and gives fast and easy access to all referenced material
-   Generates an access menu according to a general schema of how the machinery is assembled 
-   Integrates a search tool to find info across all documents here referenced

## Target Users

-   Administrators looking to estimate current installation costs. 
-   Electrician contractors installing power lines, control console.
-   Operators that need to learn correct handling of the equipment.

## Technical Preferences (optional)

-   A left hovering menu with most important themes as main page is preferred
-   A search field must be integrated somewhere in the UI design
